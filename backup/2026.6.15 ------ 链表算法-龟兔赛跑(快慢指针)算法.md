应用情景:
1.寻找中间节点；
2.判断是否为环(看快指针是否会与慢指针相遇)；
3.寻找入环节点(在第一次相遇后，将其中一个指针指向头节点，然后两个指针都向前只走一步，再次相遇即是其入环节点)；
4.寻找重复数(给出的数组类似于隐形的链表结构即寻找其入环节点)
``class Solution {
    public int findDuplicate(int[] nums) {
        // 第一阶段：寻找相遇点
        int slow = nums[0];
        int fast = nums[nums[0]];
        while (slow != fast) {
            slow = nums[slow];          // 龟：每次走1步
            fast = nums[nums[fast]];    // 兔：每次走2步
        }
        
        // 第二阶段：寻找入环节点（即重复的数字）
        int find = 0;
        while (find != slow) {
            find = nums[find];
            slow = nums[slow];
        }
        
        return find;
    }＂
